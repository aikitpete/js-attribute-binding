# attribute-binding

[![License](https://img.shields.io/github/license/aikitpete/js-attribute-binding)](LICENSE) ![ActionScript 3](https://img.shields.io/badge/ActionScript%203-E34F26) ![Adobe Flex](https://img.shields.io/badge/Adobe%20Flex-C1272D) ![Status](https://img.shields.io/badge/status-archived-lightgrey)

Experiment with property binding and value modifiers (for example capitalising or truncating text) between model objects and UI components, using Flex `[Bindable]` metadata.

**Stack:** ActionScript 3, Adobe Flex
**Status:** archived. Flash Player is end-of-life, so the demo no longer runs in current browsers.
